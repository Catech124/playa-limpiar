# Íconos del HUD

Generados con el **modelo de imágenes de Qwen** (chat.qwen.ai → "Crear imagen")
el 2026-10-26, a pedido del proyecto: estilo flat con contorno oscuro, fondo
blanco. Se procesaron con Python/PIL (fondo → transparente, recorte y 96×96).

| Archivo | Ícono |
|---|---|
| `pet.png` | botella PET |
| `vidrio.png` | botella de vidrio |
| `lata.png` | lata de aluminio |
| `reloj.png` | reloj de arena |
| `tiburon.png` | aleta de tiburón |
| `gaviota.png` | gaviota |
| `bolsa.png` | bolsa de basura llena |
